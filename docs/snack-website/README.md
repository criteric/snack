# Snack Website

A responsive, static landing page for Snack Terminal Editor.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` inside this directory.

## Publish to GitHub Pages

1. Create a public repository named `YOUR_USERNAME.github.io` (or use an existing repository and its project Pages URL).
2. Upload `index.html`, `style.css`, `script.js`, and `favicon.svg` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Wait for deployment and open `https://YOUR_USERNAME.github.io`.

## Before publishing

- Replace `https://github.com/criteric` with the confirmed Snack project repository URL when available.
- Replace the placeholder GitHub link with a release/download link once there is a verified release.
- The editor illustration is conceptual, and the listed roadmap features are not guaranteed to be available in current releases.
- The starter command button copies `snack --help`; it does not install Snack.

No frameworks, build tools, or external assets required.
