Kurulum

Windows ve Linux için kurulum kanalları hazırlanıyor. Aşağıdaki komutlar planlanan arayüzü gösterir; yayınlanmış yükleyici veya paket kaydı olmadan çalışmaz.

Windows · winget (planlanıyor)

winget install Criteric.Snack

Windows · PowerShell (planlanıyor)

irm https://criteric.github.io/snack/install.ps1 | iex

Linux (planlanıyor)

curl -fsSL https://criteric.github.io/snack/install.sh | bash

Şimdilik geliştirme durumunu ve mevcut sürümleri GitHub deposundan takip edin.
